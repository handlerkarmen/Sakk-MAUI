# Sakk-MAUI
Sakkjáték gépi ellenféllel, C# és .NET MAUI (Windows)

Teljes szabályrendszerű sakkjáték gépi ellenféllel, Windowsra.
Tanulóprojekt: a cél a szabályok, az MVVM-szerkezet és egy egyszerű sakkmotor megvalósítása volt.

## Funkciók
- Teljes szabályrendszer: sáncolás, átkelő ütés (en passant), gyalog-átalakítás választással, sakk, matt, patt
- Játékmódok: ember vs ember, gép vs ember (3 nehézségi szint, szín választható)
- Időre játszás: állítható játékidő és lépésenkénti többlet
- Lépés megerősítése, feladás megerősítéssel
- Algebrai lépéslista, a játék végén visszanézhető
- Testreszabható tábla színek (mentve JSON-ban)
- Tábla forgatása, átméretezhető ablak
